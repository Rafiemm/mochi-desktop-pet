## When you send them back

1. Save the 10 images with exactly the names above (`raincoat.png`, `overalls.png`, `sailor.png`, `winter.png`, `chef.png`, `wizard.png`, `yukata.png`, `astronaut.png`, `hero.png`, `pajamas.png`) in `Mochi\owl\outfits\src\`.
2. Optional: add `names.json` there to set the menu names, for example `{ "raincoat": "Yellow raincoat" }`.
3. From `Mochi\owl\tools`, run `node build-outfits.cjs`. It cuts out the backgrounds, lines each outfit up with her body and copies everything into the desktop app.
4. From `Mochi\desktop`, run `npm run dist` to rebuild the installer. Outfits show up in the tray icon's **Outfit** menu.

If an outfit sits a little high, low or small on her body, add `calib.json` in the same folder, for example `{ "chef": { "s": 1.03, "dy": -0.5 } }` (scale multiplier, and a vertical nudge in % of her height), and run the build again.

## About her moves in an outfit

You are making ONE image per outfit (the standing pose). In an outfit she still blinks, talks, follows the cursor, hops, waddles from side to side, swishes her tail and jumps, but she keeps her arms down. The special arm poses (waving, walking steps, arms up, thumbs-up, thinking) only exist in the pink sweater. If you want an outfit to have those too, generate extra images from the same prompt with the pose from `Mochi-prompts.md` added (for example `wave`), name them `chef.wave.png`, `chef.walkA.png`, `chef.celebrate.png` and so on, and run the build again. Any pose you provide gets used automatically.
